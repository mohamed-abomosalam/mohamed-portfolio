1. الرفع مرة واحدة
نزّل portfolio-executive-complete.zip وفك الضغط.
افتح المستودع → Add file → Upload files.
ارفع محتويات الحزمة في جذر المستودع: index.html ومجلدات ar وen وassets والملفات المرافقة.
لا ترفع ZIP نفسه، ولا تضع الموقع داخل مجلد خارجي إضافي.
اترك جميع ملفات التحقق google*.html الموجودة بالفعل؛ لا تحذف رموز التحقق الأخرى.
اضغط Commit changes، وانتظر نجاح آخر نشر في تبويب Actions.
Settings → Pages يجب أن يشير إلى main و / (root) إذا كنت تستخدم النشر من فرع.
ملف .nojekyll مرفق؛ تأكد من إظهار الملفات المخفية عند فك الضغط إذا لم يظهر لك.
الموقع ثابت ويمكن تشغيله على GitHub Pages دون إعداد npm أو خادم خلفي.

2. ما الذي جرى بناؤه
واجهة جديدة: افتتاحية بالصورة على كامل المساحة، اسم واضح، نبذة شخصية من سجل العمل الفعلي، عرض كبير للمشروعات، نموذج لطريقة العمل، الخبرة والتواصل.
التكوين يعرض دورك والنتيجة داخل سياق كل مشروع؛ لا يوجد شريط أرقام منفصل أو شعارات تسويقية عامة.
العربية والإنجليزية لهما صفحات HTML فعلية ونصوص وبيانات وصفية مستقلة.
CSS وJavaScript مدمجان في الصفحات، والخطوط والصور محلية.
Lucide: مجموعة SVG صغيرة. Anime.js: الجزء الخاص بحركة WAAPI، نحو 11 كيلوبايت قبل الضغط.
الحركة تراعي prefers-reduced-motion. التراخيص موجودة في THIRD_PARTY_NOTICES.txt.
15 صفحة محتوى، وصفحة 404، وخريطة موقع من 14 عنواناً أساسياً.
لا توجد مكتبات تحميل ضخمة أو اعتماد على CDN للخطوط أو الأيقونات أو الحركة.

3. رسالة الشكر والتقييم
الشكر موجود داخل الصفحة والتذييل.
التقييم يفتح فقط عندما يختار الزائر زر قيّم التجربة في التذييل. أزيلت الرسائل التلقائية أثناء القراءة.
يمكن إغلاقه، ولا يقفل تمرير الصفحة أو ينقل التركيز عند ظهوره تلقائياً.
اختيار واحد يُحفظ في هذا المتصفح باستخدام مفتاح النسخة السابقة نفسه.
من سبق له التقييم سيجد اختياره محفوظاً عند فتح التقييم. هذا ليس تعريفاً لشخص أو منعاً للتكرار بين الأجهزة.
إذا حُجبت Analytics لا نضمن وصول الحدث. رسالة الشكر تؤكد تفاعل الواجهة فقط.
لا توجد أرقام تقييمات عامة أو نجوم أو آراء مختلقة على الموقع.

4. Analytics
المعرف محفوظ: G-2TNQYQJ8V5. لا تُنشئ حساباً أو خاصية جديدة لمجرد تغيير التصميم.
لو عنوان تدفق البيانات قديم: Admin → Data streams → اختر تدفق الموقع → تعديل تفاصيل التدفق.
Protocol: https. Website URL: mohamed-abomosalam.github.io/mohamed-portfolio/
فعّل Enhanced measurement، ومنه تنزيل الملفات إذا أردت تتبع تنزيل السيرة الذاتية.
الأحداث:
contact_click: contact_channel, contact_topic, placement
project_filter: project_category
project_share: project_slug
service_select: service_focus
workflow_select: workflow_type
workflow_step: workflow_type, workflow_step
portfolio_feedback: feedback_value, feedback_prompt, page_type, content_language
لا تُرسل كلمات البحث أو مراجع النموذج أو نصوص رسائل واتساب في أحداث مخصصة.
لا نرسل تنزيل PDF كحدث مخصص ثانٍ بجانب Enhanced measurement.

لفصل راضٍ عن غير راضٍ، إن لم تكن أنشأت التعريف سابقاً:
Admin → Data display → Custom definitions → Custom dimensions → Create custom dimension.
Dimension name: Feedback choice
Scope: Event
Event parameter: feedback_value
Save.
Explore → Free form.
Dimensions: Feedback choice و Event name.
Metrics: Event count.
Rows: Feedback choice.
Values: Event count.
Filter: Event name exactly matches portfolio_feedback.
satisfied = راضٍ. not_satisfied = غير راضٍ.
قد تحتاج التقارير المفصلة إلى 24–48 ساعة بعد التعريف ووصول البيانات.
نتائج التقييم مخصصة لك في Analytics. عرض مجموع عام على الموقع يحتاج تجميعاً حقيقياً وخدمة خلفية غير مضافة هنا.

5. Google والبحث
التصميم يستخدم روابط الإصدار السابق نفسها. لا تحتاج خاصية جديدة بسبب التصميم وحده.
اختر الخاصية الجديدة التي أضفتها: https://mohamed-abomosalam.github.io/mohamed-portfolio/
لا تعمل داخل خاصية salama-bot القديمة.
خريطة الموقع: https://mohamed-abomosalam.github.io/mohamed-portfolio/sitemap.xml
إذا كانت أُرسلت من قبل، يظل عنوانها صالحاً. يمكنك مراجعة حالتها بعد نشر التحديث.
العربية: https://mohamed-abomosalam.github.io/mohamed-portfolio/ar/
الإنجليزية: https://mohamed-abomosalam.github.io/mohamed-portfolio/en/
افحص الرابطين ثم Test live URL، واطلب الفهرسة إن كانت الصفحة مؤهلة عند الحاجة.
الصفحات تتضمن canonical وhreflang متبادلة وبيانات منظمة ProfilePage/Person وصفحات أعمال مستقلة.
بيانات المشروع لا تحتوي AggregateRating أو تقييمات مختلقة.
لا يوجد ضمان للتصدر أو موعد ثابت للظهور؛ تكرار طلب الفهرسة لا يسرّع العملية.
لم نضف ملف robots.txt داخل مسار المشروع؛ قواعد الروبوتات تُقرأ من جذر المضيف.
إذا طلب Google ملف تحقق جديداً، ارفعه باسمه ومحتواه الأصليين بجانب index.html.

6. اختبارك بعد الرفع
افتح الرابط على الكمبيوتر والهاتف، ويمكن تحديث الصفحة بقوة Ctrl+F5.
جرّب العربية والإنجليزية ثم العودة إلى الرابط الأساسي؛ يتم حفظ اختيار اللغة في المتصفح.
جرّب القائمة على الموبايل، وإغلاقها، والتنقل إلى الأعمال والتواصل.
ابحث عن إتقان، وجرّب مرشّح الوثائق، ثم امسح البحث واختر جميع الأعمال.
افتح دراسة مشروع، وكبّر لقطة الواجهة، ثم أغلق العرض.
جرّب مسارات المختبر الثلاثة. تغيير الإصدار أو المرجع يعيد المسار.
النموذج للتوضيح فقط، ولا يحفظ المراجع أو يدير بيانات مشروع حقيقي.
افتح أزرار السعودية ومصر وتليجرام والبريد وتأكد من الوجهة.
اختيار نوع الاحتياج يجهز رسالة قابلة للتعديل؛ لا يرسلها تلقائياً.
جرّب التقييم مرة واحدة، ثم ابحث عن portfolio_feedback في Realtime.
بيانات المستخدمين لا تعادل بالضرورة عدد أشخاص مستقلين؛ الجهاز والمتصفح والحظر تؤثر على القياس.

7. المحتوى والسيرة الذاتية
الأعمال الأساسية: ECC وEnterprise DCS والأرشيف الهندسي ومحرك الصوت العربي.
الأعمال الإضافية: إتقان وتبرع ونقوط؛ تظهر عند فتح القسم أو عند وجود نتيجة بحث مطابقة.
أرقام 40% و60% و1,000+ مأخوذة من بياناتك، وليست قياساً جديداً أجريناه.
راجع ملف Mohamed_AboMosalam_CV.pdf قبل النشر: أبقينا الملف الذي قدمته، وقد تكون بيانات الوظيفة فيه أقدم من السجل الحالي للموقع.
حدّث PDF بنفس الاسم إذا احتاج تصحيحاً، دون تغيير رابط التنزيل.
أرقام واتساب ومعرف تليجرام غير مكتوبة بجوار الأزرار، لكنها موجودة في الروابط العامة لتعمل.
الصوت غير مضاف إلى هذا الإصدار.
