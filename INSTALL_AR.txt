7. تقييم التجربة — إعداد التقرير
الرسالة تظهر بعد 25 ثانية من البقاء وتصفح أكثر من نصف الصفحة. يمكن إغلاقها أو فتحها من تذييل الموقع.
حدث القياس: portfolio_feedback
معلمة الاختيار: feedback_value
القيم: satisfied / not_satisfied
يُحفظ اختيار واحد في هذا المتصفح لمنع تكراره المعتاد. لا يعادل ذلك هوية شخص حقيقية؛ تغيير الجهاز أو مسح التخزين يسمح بتقييم آخر.
لو كانت Analytics محجوبة لدى الزائر فلن تصل استجابته. رسالة الشكر لا تعني تأكيد استلامها على الخادم.
لا توجد أرقام أو تقييمات عامة معروضة على الموقع. النتائج يراها مالك الحساب في Analytics فقط.

لفصل راضٍ عن غير راضٍ:
Admin → Data display → Custom definitions → Custom dimensions → Create custom dimension.
Dimension name: Feedback choice
Scope: Event
Event parameter: feedback_value
Description: Visitor feedback on portfolio clarity
Save.
بعد إرسال البيانات وإنشاء التعريف قد تحتاج التقارير إلى 24–48 ساعة.
Explore → Free form.
Dimensions: Feedback choice و Event name.
Metrics: Event count.
Rows: Feedback choice.
Values: Event count.
Filter: Event name exactly matches portfolio_feedback.
القيم satisfied تعني راضٍ، وnot_satisfied تعني غير راضٍ.
Realtime يعرض الحدث قبل اكتمال تجهيز التقرير التفصيلي.
لا تحوّل التقييمات إلى AggregateRating في البيانات المنظمة.
